# Catalogue du kit WAOUP

Les skills déjà écrites, disponibles comme base à personnaliser. Reprendre plutôt que réécrire :
la forge part de ces fichiers, remplace les structures par celles de la maison, et enrichit les pièges.

## Socle (plugin `waoup`)

| Skill | Ce qu'elle fait | À personnaliser en priorité |
|---|---|---|
| `restitution-entretien` | verbatim vers restitution en six blocs | les six blocs, le nombre d'enjeux |
| `guide-entretien` | brief vers trame d'entretien en cinq temps | les hypothèses types par typologie de mission |
| `passe-critique` | relecture en associé exigeant, trois faiblesses | la grille de lecture maison |
| `voix-waoup` | retire les tics IA, pose la voix maison | le lexique signature, les interdits |
| `mise-en-forme-charte` | Markdown vers HTML chartée, PDF, PPTX | le fichier de charte, les gabarits |
| `anonymisation` | prépare un document avant partage | les trois niveaux, la liste des interdits |
| `propale` | brief et restitution vers proposition commerciale | toute la structure : c'est le chantier ouvert |
| `defis` | restitution vers défis en questions | le nombre de défis, les axes de priorisation |
| `synthese-marathon` | matière d'atelier vers synthèse | le déroulé type des marathons |
| `deck-investisseur` | business plan vers deck en douze parties | les douze parties, le niveau de preuve |

## Commerce (plugin `waoup-commerce`)

| Skill | Ce qu'elle fait | À personnaliser en priorité |
|---|---|---|
| `compte-rendu-rdv` | note vocale vers compte rendu et bloc CRM | les champs du CRM |
| `panorama-entreprise` | nom de société vers fiche avant rendez-vous | les sources de référence |
| `business-case` | choisit et raconte le bon cas client | la bibliothèque de cas et les droits de citation |

## Ce qui n'existe pas encore

Ces besoins ont été exprimés mais ne sont pas outillés. Les proposer quand le profil correspond :

- la synthèse stratégique longue (le passage du fond à un point de vue tranché) ;
- l'étude de marché avec la place laissée à l'intuition de l'équipe ;
- la fiche de suivi de projet multi-missions ;
- la préparation d'un comité de pilotage.
