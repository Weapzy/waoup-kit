# Mots creux, kit WAOUP, skill voix-waoup
#
# Une expression par ligne. Tout ce qui suit « # » est un commentaire.
# La casse et les deux formes d'apostrophe (' et ’) sont ignorées à la lecture.
# Les espaces internes tolèrent les espaces multiples : « il  convient  de » est trouvé.
#
# Un « ? » en tête de ligne signale une expression dont le caractère fautif
# dépend du sens. Le script la sort en « à vérifier », le rédacteur arbitre.
# Exemple : « levier » est creux dans « actionner les bons leviers », légitime
# dans « le levier de la benne ».
#
# Cette liste est faite pour grossir. Quand un mot revient dans une relecture,
# on l'ajoute ici, pas dans la conversation.

# Vocabulaire maison WAOUP : à ne jamais signaler
# ---------------------------------------------------------------------------
# Les quatre phases de la méthode 4D sont des noms propres de méthode, pas du
# jargon. Décoder, Designer, Démontrer, Déployer. De même pour « défis »,
# « restitution », « marathon », qui désignent des livrables nommés.
# Ces mots ne figurent pas dans la liste ci-dessus, et ne doivent pas y entrer.
